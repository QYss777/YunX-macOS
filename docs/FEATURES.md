# 功能清单

> 概览见 [README](../README.md) ｜ 桌面版与上游 Android 版的差异见 [与上游的差异](UPSTREAM-DIFF.md)

## 解析与下载

- **分享链接解析**：识别夸克 / UC / 迅雷 / 百度 / 139 / 123 的分享链接，自动匹配提取码（可直接粘贴带提取码的整段文本）；
  另支持 GitHub 仓库 / 账号 / 文件直链
- **中文口令解析**：粘贴「绝对有效 咐置松君杂货铺叩苓」这类**不是链接的中文口令**也能解析 ——
  先试迅雷口令接口，无结果再问星海口令服务换回 `pwdId` 并合成标准分享链接，后续提取码 / 登录 / 列表 / 取链全走既有链路
  （口令原文会发往第三方服务，失败日志只记长度与原因，不落口令本体）
- **高速下载**：Range 分片并发 + 断点续传 + 失败自动重试 + 全局限速（令牌桶）；弹性区按字节顺序分配，
  保证分片物理相邻、连接复用率稳定
- **分片级 SHA-256 校验**：分片写入时增量算摘要（不额外读盘），合并时逐片重算比对，
  内容不一致即拒绝保存损坏文件；另可开启「全量 SHA-256」（合并顺带算，见「诊断与日志」）
- **下载线程数**：按网盘平台分别设置（最高 512），随时可调
- **任务并发控制**：限制同时下载的任务数（默认 1，前台任务吃满带宽，其余排队）
- **临时转存清理**：百度 / 迅雷取链后清理；夸克保留到下载完成或删除任务后清理
- **暂停 / 继续**：暂停时以磁盘分片实际大小为准回写进度，恢复后进度不跳变
- **任务持久化**：进度按时间节流落盘，重启后任务状态与进度可恢复

## GitHub 解析

GitHub 为代码托管平台（仓库 / 账号 / 文件直链），非网盘；其链接与网盘分享链接同入口解析。

- **链接识别**：识别仓库主页、账号（用户 / 组织）主页、仓库子路径（`tree` / `blob`）、`releases/latest`、
  发布资产直链与 `raw` 直链；可直接粘贴含 GitHub 链接的整段文本
- **浏览**：仓库文件树 / Releases / 账号（用户或组织）仓库列表；分页「加载更多」、显示 fork 来源、
  目录条目显示「最后提交时间」
- **README 渲染**：GFM Markdown（表格 / 代码 / 折叠 / 图片）；图片经自研加载器渲染（不使用 Coil），
  走 OkHttp 拉取 + Skia 解码，带内存缓存与加载中 / 失败占位，支持镜像前缀加速
- **下载**：GitHub 文件 / ZIP 加入现有下载任务，支持镜像前缀加速，失败可回退原始 GitHub 直链
- **Token（可选）**：Personal Access Token 仅用于提升 API 限额（未认证 60 次/小时，认证后 5000 次/小时）；
  经 AES-GCM 加密存储（桌面版密钥文件 `credential.key`）、输入框掩码显示、不写入日志；
  API 返回 401 时自动清除 Token 并提示

## 任务管理

- 暂停 / 继续 / 删除
- 打开文件 / 在 Finder 中显示（直接定位到目标文件）
- 复制直链 / 复制分享链接
- 下载完成项一键定位「文件夹」

## 通知与保活

- **应用内下载进度**：下载页实时显示多任务进度、速度与完成度；macOS 通知用于任务完成提示，是否显示受系统通知设置影响
- **完成通知**：全部任务下载完成时额外提示一条
- **阻止电脑休眠**：下载期间通过 macOS 原生电源管理接口阻止系统睡眠，任务结束自动恢复

## 登录与账号

- **内嵌浏览器登录（推荐）**：夸克 / UC / 百度 / 139 在应用内打开真实 Chromium 页面（JCEF 132），
  登录后自动检测并保存 Cookie，全程无感
- **一键导入本机浏览器 Cookie**：扫描 Chrome / Edge / Firefox，用 macOS Keychain Safe Storage 派生密钥并以 AES-CBC 解密 Chromium Cookie；Firefox Cookie 直接读取明文值
- **手动粘贴 Cookie**：兜底方式
- **迅雷**：账号密码 + 短信验证（验证页由系统浏览器承载）；**123 云盘**：账号密码换 JWT
- **登出彻底清除 Cookie**：通过 CEF 的 `delete` 标志清除该平台全部 Cookie，避免残留
- **认证备份**：用户口令派生密钥（PBKDF2）+ AES-GCM 加密 Cookie / JWT，导出 `.yunx` 备份文件，可跨设备恢复

## macOS 系统集成

- **菜单栏托盘**：点击菜单栏图标恢复主窗口，菜单提供显示窗口与退出操作
- **菜单跟随系统配色**：深色 / 浅色切换后菜单随 macOS 外观变化
- **关闭行为可选**：每次询问 / 直接退出 / 最小化到菜单栏
- **原生文件对话框**：下载目录选择、备份导入 / 导出使用 macOS 原生文件选择器
- **下载目录解析**：默认使用用户的「下载」文件夹，也支持自定义路径
- **剪贴板分享链接检测**：主窗口不在前台时检测剪贴板，发现分享链接后弹出提示卡片，
  点击即打开解析（可在设置中关闭）
- **Finder 文件定位**：下载项可在 Finder 中直接显示并选中目标文件
- **休眠控制**：下载期间阻止 Mac 进入睡眠，任务结束后自动恢复
- **启动与关闭过渡**：启动闪屏 + 主窗口内容就绪后渐入；关闭时先淡出再销毁，避免白屏闪烁

## 界面与体验

- 深色模式 + 自定义种子色（Monet 风格动态取色）
- 链接收藏；解析链接历史（1 小时去重，支持搜索 / 复用提取码 / 删除 / 清空）
- 弹窗统一为窗口内覆盖层渲染，不创建原生窗口，避免阻塞 UI 线程与动画卡顿
- 渲染后端可选：默认 `OPENGL`（动画流畅且文字清晰），
  可用环境变量 `YUNXPC_RENDER_API=SOFTWARE|OPENGL` 切换
- 更新检测：**启动时自动检查**（网络失败 / 已是最新 / 已选「不再提示该版本」的版本静默不打扰，
  「不再提示」按版本记住、不是全局关闭），设置页也可手动检查；
  读取 GitHub Releases 并提示新版本，可自行选择安装包或便携包，更新说明以 Markdown 渲染
- **网络设置**：GitHub 下载镜像前缀（留空使用内置默认镜像）、网络代理（不使用代理 / 使用系统代理 / 手动配置，默认直连，启动与设置变更时装配）
- **实验性功能**（设置 → 实验性功能二级页）：集中管理高风险 / 可调下载参数，支持一键重置为默认值 ——
  HTTP/2 开关（默认关闭，仅使用 HTTP/1.1；开启后允许 ALPN 协商 h2）、
  下载读缓冲大小（默认 64KB；档位 16/32/64/128/256/512/1024 KB，也可直接输入 **16–4096 KB** 内任意值）、
  慢连接抢占（默认开启，默认 12KB/s · 15 秒；阈值 **4–10240 KB/s**、判定时长 **5–600 秒**，均支持档位选择或直接输入）、
  主页快捷方式（默认关闭，开启后在解析页以横向快捷方式展示收藏，点击直达解析）。
  ★ 每个数值项都分「**合理范围**」与「**硬上限**」两档：读缓冲合理 16–1024 KB、阈值合理 4–1024 KB/s、时长合理 5–120 秒；
  超出合理范围时会弹确认框提醒（仍可启用，但内存占用/速度/稳定性等风险与后果由使用者自行承担，开发者不对此负责）

## 诊断与日志

- **导出日志**（设置 → 导出日志）：导出运行日志文本（可「在文件夹中显示」或「保存到下载目录」），含系统 / Java 版本头部信息
- **诊断模式**（设置 → 关于 YunX-OS → 长按 → 开发调试 → 诊断模式，默认关闭）：开启后把
  `db / crypto / download / webview / network / operation` 六个模块的详细日志**按模块分文件**写进
  `<数据目录>/diagnostic_logs`，跨重启保留；带全局限流（300 行/秒）与自动轮转（单文件 2MB、每模块 5 份、总量上限 10MB），
  **关闭时一行都不写**（调用点零开销）。敏感信息经过脱敏：URL 走 `LogRedactor`、请求体/响应体只在
  非 200/206 或抛异常时记录（各截 1.5KB）、凭证只记用途与长度不记内容
- **导出诊断日志（zip）**：先 flush 再打包成 `yunx_diagnostic_logs_<时间戳>.zip`，便于把复现步骤对应的完整日志一次带走
- **下载调试**（设置 → 关于 YunX-OS → 长按 → 开发调试 → 下载调试，默认关闭）：按**任务**记录事件流
  （入队 / 断点失效 / 分片规划 / 抢占慢连接与结果 / 网络变化 / 合并与校验 / 完成 / 失败 / 暂停 / 删除 …）。
  开启后**右键下载任务 → 调试信息**可进调试页：任务卡 + 全局资源（在飞配额 / 活跃任务 / 线程池 / 堆内存）+
  线程表（每个在飞分片由哪个 worker 负责、区间、已收、瞬时速度、抢占次数，可「重连」强制换连接）+
  实时日志跟随（等宽字体，可复制快照 / 导出完整下载日志）。数据为拉取式、只活在内存，**不打开调试页时零额外开销**；
  **关闭开关会清空全部调试日志**（有二次确认）
- **全量 SHA-256**（仅在「下载调试」开启时可见，默认关闭）：保存文件时顺带算出整文件摘要写进调试日志；
  与合并复用同一遍 IO，不额外读盘，只多一点 CPU

## 数据与备份

- **储存目录**（设置 → 储存目录，二级页）：集中管理三处位置，都可改且**重启后生效**，切换时自动搬迁旧数据
  - **下载保存目录**：下载完成后的落盘位置（默认系统「下载」；内置下载器与 Gopeed 引擎共用）
  - **下载缓存目录**：分片 / 合并临时文件 / 内嵌浏览器数据（含网页登录态）；预设「默认（用户目录）/
    应用所在目录（便携）/ 自定义」
  - **数据库位置**：`yunx.db` 与 `credential.key`（库内凭证用它加密，必须同处一地）；
    目标目录已存在 `yunx.db` 时拒绝切换
  - **数据库加密等级**（立即生效，无需重启）：控制凭证主密钥怎么保护。三档都只重新包裹 32 字节主密钥，
    不动库内数据：

    | 档位 | 库文件 | 凭证列 | 密钥 `credential.key` |
    | --- | --- | --- | --- |
    | **宽松** | 明文 SQLite | AES-256-GCM | 明文（换机器 / 便携版用这档） |
    | **普通**（默认） | 明文 SQLite | AES-256-GCM | 本机派生密钥包裹（PBKDF2 21 万次；绑定本机） |
    | **较为严格** | 明文 SQLite | AES-256-GCM | macOS Keychain 保护（绑定当前用户） |
    | 严格 | 整体加密 | — | SQLCipher + Keychain（**暂未支持**） |

    ⚠ 数据库位置改到「应用所在目录 / 自定义」时，界面会提示：若要当便携版带到别的 Mac，
    加密等级需切回「宽松」—— 本机派生密钥与 Keychain 都是绑定本机的，换机后无法解密（凭证需重新登录）。
- **认证备份**：用户口令派生密钥（PBKDF2）+ AES-GCM 加密 Cookie / JWT，导出 `.yunx` 备份文件，可跨设备恢复

数据目录说明见 [使用说明](USAGE.md)。
